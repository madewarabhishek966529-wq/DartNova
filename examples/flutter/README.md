# DartNova Flutter Library

**Motion for Flutter** — Production-ready, zero-pub-dependency animated UI components.

## Available Widgets

### Buttons & Micro-interactions
- `NovaPopButton`: Spring press scale response with glow.
- `RadialGlowButton`: Pointer-following radial gradient spotlight.
- `CornerButton`: Sci-fi beveled chamfer polygon button.
- `MagneticButton`: Proximity-attracted floating button.

### Text & Transitions
- `TypingText`: Character-by-character typewriter reveal with blinking cursor.
- `TextReveal`: Masked slide-up editorial reveal.
- `StaggeredText`: Staggered word animation sequence.

### Cards & Images
- `Cursor3DCard`: 3D perspective parallax tilt with light reflection.
- `ImageTrailCanvas`: Pointer-tracking organic image stamps.
- `DiagonalCarousel`: 3D angled skew card gallery.
- `AnimatedCardStack`: Cascading interactive card deck.

### Avatars & Tooltips
- `AvatarGroup`: Overlapping avatars with hover expansion.
- `TooltipAvatar`: Interactive popover profile card.

### Backgrounds & Effects
- `AnimatedGradientMesh`: Continuous shifting multi-color gradient field.
- `WaveAnimation`: Dual-frequency procedural sine wave animation.
- `NeonGradientCard`: Pulsating neon perimeter border aura.
- `ParticleMotionCanvas`: Constellation physics nodes with distance vectors.
- `AnimatedWelcomeScreen`: Full onboarding motion canvas.
- `SpotlightEffect`: Interactive flashlight beam on dark surfaces.
- `NovaShimmer`: High-speed skeleton shimmer sweep.

## Usage

Simply import the component files into your Flutter project's `lib/` directory or reference them directly.
All widgets require only core `flutter/material.dart`.
